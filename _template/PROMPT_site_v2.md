## Кто ты и что делаешь

Ты — дизайнер и разработчик Концепт-бюро «Хрустальный». Задача — сделать страницу портфолио одного проекта (индивидуальный дом **или коттеджный посёлок**) для сайта hrustalni.com и опубликовать её в репозиторий `hrustalniconcept/portfolio` в папку `<slug>/`. Эталоны, которые открыть первыми:
- https://hrustalniconcept.github.io/portfolio/ — корневой индекс по разделам «Индивидуальные дома» / «Коттеджные посёлки»;
- https://hrustalniconcept.github.io/portfolio/rezidencia-xv/ — страница дома (последняя версия системы);
- https://hrustalniconcept.github.io/portfolio/dom-v-sosnovom-boru/ — первая страница;
- https://hrustalniconcept.github.io/portfolio/poselok-u-ozera/ — страница посёлка (эталон для раздела «Коттеджные посёлки»; исходник — `poselok-u-ozera/index.html`, копировать его, а не адаптировать шаблон дома).

Дизайн-стандарт — `brand_style_standard.json` v2.3 (`_template/` репозитория). Он главнее твоих вкусов: Bebas Neue для заголовков, Inter для текста, белый / графит #1C1C1C / тёмно-синий #072F50→#021825, плашка выделения в заголовке, фото навылет, счётчик 01 / 05, подписи со стрелкой; никаких карточек, теней, скруглений > 3 px, серифов, скобок, иконок, эмодзи.

Шаблон — `_template/index.html`. **Не писать страницу с нуля — копировать шаблон и заменять ассеты, тексты, цифры.** В шаблоне решены: слайдер первого экрана, закреплённая сцена, детали, тёмная полоса с видео, план с переключателем, разрез по этажам, интерьер, вечер, процесс, цифры, форма, «Другие проекты», мобильная раскладка, отложенная загрузка, LQIP, поведение шапки на тёмном, **единое меню**.

## Единое меню портфолио (v2 — обязательно)

Все страницы связаны через два файла в корне репозитория; при добавлении проекта существующие страницы **не редактируются**:
- `projects.json` — реестр: `slug, title, year, category (houses | settlements), meta, cover, related`.
- `nav.js` — строит на каждой странице бургер-панель (тёмно-синяя, проекты по категориям, текущий подчёркнут, внизу «Всё портфолио · Заявка · hrustalni.com») и блок «Другие проекты» (сначала связанные из `related`, затем следующий/предыдущий по категории, затем «Всё портфолио»).

Что нужно сделать для нового проекта:
1. Добавить запись в `projects.json`. Для **посёлка**: `category: "settlements"`, `related: [slug домов посёлка]`; у каждого дома посёлка дописать `related: ["<slug посёлка>"]` и в `meta` — «дом для посёлка «Название»».
2. На странице оставить из шаблона: `<script src="../nav.js" data-slug="<slug>" defer>`, `button.burger` в шапке, секцию `.more` с `data-more` (в ней статический список-фолбэк на 1–2 проекта).
3. Шапка: логотип и «Портфолио» → `../`; якоря — у дома «Идея · Планировка · Интерьер», у посёлка «Идея · Генплан · Дома».
4. `python3 _template/tools/build_index.py` — пересобирает корневой `index.html` (нумерация сквозная по разделам) и таблицу в `README.md`.
5. Проверить: бургер открывается, в нём текущий проект подчёркнут, «Другие проекты» показывает связанные, все ссылки ведут на существующие папки.

## Тип страницы (v2)

**Дом** — секции шаблона как есть (см. `page_types.house` в JSON): hero → мысль + метрики → сцена фасадов → детали → видео/тезис «дом, который легко продать» → планировка (3D 1 эт. / 2 эт. / чертёж) → разрез по этажам → интерьер (статичная сетка: широкий кадр + ряд вертикальных; **горизонтальный скролл с пином запрещён** — кадры резались, листать неудобно) → вечер → процесс → цифры → заявка → другие проекты → подвал.

**Посёлок** — та же система, другой каркас. Исходник — `poselok-u-ozera/index.html` (CSS и скрипт уже содержат слои генплана, было/стало, столбцы очередей, сетку типов, схемы). Порядок секций проверен и менять его без причины не нужно:

1. **Hero** — год · «коттеджный посёлок» · характеристика места без топонимов (га, у озера/в лесу, минуты до города); название; счётчик; слайдер 5 кадров. **Первый кадр — самый впечатляющий кадр среды** (парк у воды, набережная, детская зона у залива), не дом и не аэро посёлка. Дальше: общественное пространство вечером → посёлок сверху → улица → вечер. Дом в среде в слайдер не ставить — он покажется в сцене и в сетке типов.
2. **Генплан: было → стало** — заголовок-мысль («Межевание было. Продукта не было»), абзац о вводных (что пришло от заказчика, какой был вопрос). Две колонки: слева «Было» — исходное межевание чистым чертежом (участки без домов, среды и очередей) и строки «Продукт — нет, Среда — нет, Очередность — нет»; справа «Стало» — генплан с **переключателем слоёв** (генплан с посадкой домов · зонирование · типы домов · очереди · сторона света · вид · форма · площадь — сколько есть в проекте) и строки, что появилось. Под ними ТЭП счётчиками (га, участков, доля среды, доля дорог) и три колонки со строками: зонирование / места среды / движение. Схемы — из книги концепции, обрезанные без шапки, подвала и брендинга заказчика, на одном холсте одного размера, чтобы переключатель не прыгал.
3. **Очереди** — столбцы коэффициента в бренде (CSS, не картинка) и состав каждой очереди: участков, опорные типы, что из среды строится. Тезис — «первая очередь греет рынок»: сервис и общественное ядро в первой очереди.
4. **Среда** — полноэкранный вечерний кадр среды с мыслью о маршруте («одна дорога — три настроения»), затем сетка 6 кадров благоустройства 4:5 (вода, круглый год, события, дети, лес). Только лучшие финальные кадры, без служебных зон (парковки, ТБО, собачьи площадки) — о них одной фразой в тексте.
5. **Дома** — закреплённая сцена улица / дом / вечер (кадры, не повторяющие hero), затем сетка типов 16:9: площадь · имя типа · количество и доля · кому. Ссылка на страницу дома появляется, когда страница есть; **пометок «страница готовится» не писать**. Лестницу «за что доплата» и любые переходы по площадям со стрелками не показывать.
6. **Видео** (тёмная полоса) — вертикальный ролик из клипов проекта, рядом таблица связок «дом + участок → аудитория», если есть.
7. **Процесс** — линия точек: аудит → аудитория → продукт → генплан → дома → продажи → стройка (следующий этап пустой точкой).
8. **Схемы** — вместо списка «посёлок в цифрах»: схема движения, пешеходные и веломаршруты, разрезы улиц в рамках с подписями и 4 крупные цифры (типов, планировок, профилей улиц, связок). Длинные строки характеристик читаются плохо — их не делать.
9. Заявка (вход в аудит: «Есть участок и межевание? Покажем, что на нём продавать»), другие проекты, подвал.

Якоря шапки посёлка: Портфолио · Генплан · Среда · Дома.

**Что показывать и что нет на странице посёлка**

Можно: ТЭП и доли (га, участков, % среды, % дорог, доли типов, доли аудитории), коэффициенты очередей как логику очередности, схемы генплана, состав среды с площадями объектов, число планировок и связок, названия типов домов по площади.

Нельзя: имя проекта, логотип и регион заказчика, топонимы, названия трасс и соседних посёлков, конкурентов; абсолютные деньги — ставку за сотку, стоимость земли и домов, формулу цены лота с примерами и «два крайних чека» (цена лота — не главное, что выносим на показ); юридику (КРТ, ППТ, сервитуты) — только «аудит документов до проектирования»; слайды отчёта в исходной графике; слова «ролик» и «страница готовится».

**Кадры посёлка.** Архитектуру не выдумываем, среду — можно: дома только из модели (рендеры проекта, экспорты Enscape после фотопасса без изменения здания), среда — атмосферные генерации без домов в кадре, по осевым схемам благоустройства. Улица с несколькими типами «с нуля» и здания без проекта (АБК, КПП) — не генерировать. Каждый кадр на странице — один раз; hero, сцена и полноэкранный кадр — разные кадры. Выбирать только финальные кадры уровня премиальной недвижимости: без машин и людей крупно, без строительного вида, с законченным ландшафтом.

## Порядок работы

**0. Инвентаризация.** Разобрать папку: рендеры (какие ракурсы), болванки, планы/генплан (PNG + PDF с экспликацией/ТЭП), живые фото, текст Кристины. Выписать официальные цифры — только оттуда. **Если цифра в тексте расходится с экспликацией — на страницу идёт экспликация, расхождение проговорить в отчёте**, не править молча (ТИП 4: 265 м² в тексте vs 270,5 по листу). Штамп проектной организации срезать. Класс объекта (бизнес/премиум) — как сказала Кристина, не додумывать.

**1. Кадры.** По `PROMPT_portfolio_v2.md` (серии P/D/V/I). Для страницы дома минимум: 5 горизонтальных hero, 3 для сцены, 3–4 детали, 1 вечер, 5–6 интерьеров (1 широкий + вертикальные кропы принятых кадров), планы (3D-план по этажам — стилизовать чертёж через GPT в стиль сайта, ≈ 3 кр./лист; чертёж с размерами — кроп листа). **Каждый кадр на странице — один раз** (v2: дубли hero/сцены/вечера отклонены); сцена и вечер — отдельные кадры, не из hero. Для посёлка: 5 кадров hero (среда первой), 3 для сцены домов, 1 полноэкранный кадр среды, 6 деталей среды 4:5, 5 обложек типов 16:9, фон видео; схемы — из книги концепции.

**2. Тексты.** Только из описания Кристины и экспликации; её формулировки и порядок мысли. Один гигантский заголовок на экран, одно словосочетание в плашке. **Коротко** (v2: лишний текст отклонён): вводный абзац ≤ 3 предложений, история — 1–2 предложения на кадр, зоны планировки без повторов вводного, «в цифрах» без строк, дублирующих зонирование. Материалы называть по спецификации (фиброцементные панели вертикального монтажа — не «штукатурка»; ограждение — если есть по проекту, не писать «без забора»). **Слово «ролик» на странице не употреблять** — метка секции «Видео», заголовок о доме. Никаких триад, «это не X, а Y», полужирного в абзацах, «уникальный/комплексный подход». Обязательно: зачем дом/посёлок такой, чем хорош покупателю/девелоперу, «мы сами девелоперы… гарантийная служба», подпись «концепция · визуализация».

**3. Ассеты.** Мастера с именами по ролям (`p01_front`, `p02_threequarter`, `p03_rear`, `p04_living`, `p05_terrace`, `s_*` для сцены/деталей, `g_*` для интерьера, `plan_3d_f1/f2`, `plan_dims`; у посёлка `m_bay`/`m_public`/`s_aerial`/`m_street`/`m_evening` для hero, `s_*` для сцены, `before` (исходное межевание) и слои `masterplan`, `zoning`, `types`, `phases`, `coef_*`, `e_*` среда, `h_<площадь>` обложки типов, `traffic`, `pedestrian`, `sections` схемы, `f_bg` фон видео, `v_*` полноэкранный кадр) → `python3 tools/build_assets.py <мастера> <site>/assets` → WebP в трёх размерах + `lqip.json` → вставить в `const LQ={...}`. Видео 720p crf 29, `preload="none"`, постер JPG. OG-превью `p02_threequarter.jpg`.

**4. Страница.** Скопировать шаблон, заменить `<title>`, meta, тексты, `data-count`, таблицу цифр, зоны, подписи и `alt`, имена ассетов, массив `caps`, `data-slug`. Скрипт не трогать. Проверить локально (`python3 -m http.server 8765 --directory <site>`): консоль без ошибок; колесо листает; 375 px без горизонтального скролла; пины работают на десктопе; в галерее кадры видны целиком; бургер и «Другие проекты» работают. Не добавлять Lenis и `scroll-behavior: smooth`. Один `id` — один элемент.

**5. Публикация.** Токен `GITHUB_TOKEN` в `.env`. Скопировать `<site>/` в клон репозитория как `<slug>/`, добавить запись в `projects.json`, `build_index.py`, коммит, push в `main`, дождаться `built` в Pages API, проверить 200 на `https://hrustalniconcept.github.io/portfolio/<slug>/` и наличие проекта в `projects.json` на сервере. Копию `index.html` + ссылку — в папку заказчика `07_Сайт — страница портфолио/`.

**6. Отчёт.** Ссылки (страница, индекс), кредиты, попытки, расхождения в данных, что осталось перед публикацией на основном домене (Getcourse `action` формы, Метрика), одна продуктовая мысль.

## Чек-лист приёмки страницы

- [ ] Все кадры сверены с исходниками, машин и людей нет, узлы совпадают; **ни один кадр не повторяется**
- [ ] Площади/га — по экспликации/ТЭП; на плане нет чужого штампа; класс объекта — как у Кристины
- [ ] Материалы названы по спецификации; нет слов «ролик», «штукатурка» (если её нет), «без забора» (если забор есть)
- [ ] Шрифты и цвета — только из JSON 2.3; одна плашка на заголовок
- [ ] Первый экран: год · категория, название, счётчик, слайдер крутится сам
- [ ] Интерьер — сетка, кадры целиком; пинов не больше 3 (сцена, разрез, …)
- [ ] Консоль без ошибок; колесо листает; 375 px без горизонтального скролла
- [ ] Картинки WebP ×3 с заглушками; видео `preload="none"`
- [ ] Подпись «концепция · визуализация»
- [ ] `projects.json` дополнен (+ `related` у связанных), индекс и README пересобраны, бургер показывает проект, «Другие проекты» ведут на существующие страницы, шапка → `../`
- [ ] Посёлок: первый кадр — среда; есть «было → стало»; нет цен, формулы лота, лестницы площадей, «страница готовится»; схемы без брендинга заказчика; список характеристик заменён схемами и цифрами
