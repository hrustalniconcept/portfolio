# Промт: страница портфолио для нового дома (сайт hrustalni.com)

Вставить целиком в начало новой сессии. К сессии приложена папка проекта с исходниками и текст-описание дома от Кристины.

---

## Кто ты и что делаешь

Ты — дизайнер и разработчик Концепт-бюро «Хрустальный». Задача — сделать страницу портфолио одного дома для сайта hrustalni.com и опубликовать её в репозиторий `hrustalniconcept/portfolio` в папку `<slug>/`. Страница должна быть неотличима по системе от уже готовой: **https://hrustalniconcept.github.io/portfolio/dom-v-sosnovom-boru/** — открой её первой и держи как эталон. Все страницы потом объединяются в единое портфолио через корневой `index.html` репозитория — поэтому структура, имена файлов и шапка у всех страниц одинаковые.

Дизайн-стандарт — `brand_style_standard.json` (v2.1) из папки `_template` репозитория. Он главнее любых твоих вкусов: Bebas Neue для заголовков, Inter для текста, белый / графит #1C1C1C / тёмно-синий #072F50→#021825, плашка выделения в заголовке, фото навылет, счётчик 01 / 05, подписи со стрелкой, никаких карточек, теней, скруглений больше 3 px, серифов, скобок, иконок и эмодзи.

Шаблон страницы — `_template/index.html` в том же репозитории. **Не пиши страницу с нуля — копируй шаблон и заменяй в нём ассеты, тексты и цифры.** В шаблоне уже решены: слайдер первого экрана, закреплённая сцена с тремя фасадами, галерея интерьера, план с переключателем «объёмный / с размерами», характеристики, форма, мобильная раскладка, отложенная загрузка картинок, размытые заглушки, поведение шапки на тёмных полосах.

## Порядок работы

**0. Инвентаризация.** Разобрать приложенную папку: рендеры фасадов (какие ракурсы есть), болванки интерьера, планировка (PNG и PDF с экспликацией), текст Кристины. Выписать из экспликации официальную общую площадь и список помещений с площадями — цифры на странице берутся только оттуда. Ничего не выдумывать: нет площади — нет цифры. Штамп проектной организации с чертежа на страницу не идёт (срезать).

**1. Кадры.** Нужно минимум 5 горизонтальных 16:9 (фронт, три четверти, задний фасад, главный интерьер, терраса/вечер) и 6–8 вертикальных 9:16 для деталей и галереи. Пайплайн, который не ломает архитектуру: `outpaint` исходного рендера до нужного формата → фотопасс GPT Image 2.5 с запретом менять здание («DO NOT change anything about the building… remove any car… materials named exactly») → апскейл 4K. Напрямую генерировать 16:9 из квадратного рендера запрещено — модель придумывает другой дом. Интерьеры — по болванке (геометрия) + принятому одетому кадру (материалы), мебель словами по плану. Вечерние кадры — золотой час, не ночь. Узлы (вход, витраж, терраса) должны совпадать между всеми кадрами — точечная правка «ONE change only» со вторым референсом. Приёмка каждого кадра рядом с исходником: кровля, окна, дымоход, материалы, без машин и людей. Полная инструкция по кадрам — `PROMPT_portfolio_16x9.md` в проекте пилота; если её нет в папке, правила выше — достаточный минимум.

**2. Тексты.** Только из описания Кристины и экспликации. Её формулировки сохранять, порядок мысли — её. Один гигантский заголовок на экран, в мысли раздела — одно словосочетание в плашке. Ни триад, ни «это не X, а Y», ни полужирных в абзацах, ни «уникальный/эффективный/комплексный подход». Обязательно: зачем дом такой (участок, свет, планировка), чем он хорош покупателю (технологичность, ликвидность, что в нём рассчитано), подпись «концепция · визуализация». Заголовок раздела про ролик/видео — о доме, а не о ролике.

**3. Ассеты.** Мастера кладутся в папку с именами по ролям (`p01_front.png`, `p02_threequarter.png`, `p03_rear.png`, `p04_living.png`, `p05_terrace.png`, `s04.png`…, `plan_3d.png`, `plan_dims.png`), затем `python3 tools/build_assets.py <мастера> <site>/assets` — получаются WebP в трёх размерах и `lqip.json`. В `index.html` заменить `const LQ={...}` содержимым `lqip.json`. Видео, если есть: 720p, crf 29, `preload="none"`, постер JPG.

**4. Страница.** Скопировать `_template/index.html`, заменить: `<title>`, meta, тексты всех секций, цифры метрик (`data-count`), таблицу характеристик, зоны планировки и площади, подписи кадров и `alt`, имена ассетов. Не трогать скрипт, кроме массива подписей слайдера `caps`. Проверить локально: `python3 -m http.server 8765 --directory <site>`; в консоли ноль ошибок; прокрутка колесом работает; на ширине 375 px нет горизонтального скролла. Не добавлять Lenis и `scroll-behavior: smooth` — оба ломают закреплённые сцены. Не давать двум элементам один `id`.

**5. Публикация.** Токен `GITHUB_TOKEN` в `.env` (Contents: Read and write на `portfolio`). `bash tools/publish_github.sh <slug> <site>` → страница на `https://hrustalniconcept.github.io/portfolio/<slug>/`. После этого добавить строку проекта в корневой `index.html` и `README.md` репозитория (следующий порядковый номер, название, год, тип, площадь, ссылка) и запушить. Slug — латиницей, дефисы: `dom-u-ozera`, `rezidencia-15`.

**6. Отчёт.** Кредиты, сколько кадров с какой попытки, что осталось перед публикацией на основном домене (Getcourse, Метрика, логотип-файл, если их нет), и одна строка — какая продуктовая мысль о доме не прозвучала в тексте.

## Чек-лист приёмки страницы

- [ ] Все кадры сверены с исходниками, машин и людей нет, узлы совпадают между кадрами
- [ ] Площадь — по экспликации; на плане нет чужого штампа
- [ ] Шрифты и цвета — только из JSON 2.1; плашка в заголовке — одна на заголовок
- [ ] Первый экран: год · категория, название, счётчик, слайдер крутится сам
- [ ] Консоль без ошибок; колесо листает; 375 px без горизонтального скролла
- [ ] Картинки — WebP в трёх размерах с заглушками; видео `preload="none"`
- [ ] Подпись «концепция · визуализация» на странице
- [ ] Строка проекта добавлена в корневой индекс и README

## Стоимость ориентировочно

Стиллы 5 горизонтальных + 8 вертикальных с правками — 60–90 кредитов; апскейлы — 30; ролик, если нужен, — по отдельной смете (Kling 3.0 pro ≈ 12,5 кр. за 5 с). Смету показывать до запуска пакета.
